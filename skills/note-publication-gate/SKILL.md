# note-publication-gate

## 役割

公開、投稿、予約確定ボタンを押す直前で停止し、現在会話の明示承認を確認する。

## 入力

- note アカウント。
- 対象記事の local draft path と Note editor/draft URL。
- 公開方式。即時公開、予約投稿、下書き保存のみのいずれか。
- 予約投稿の場合は日時と timezone。
- QA、画像権利、タグ、マガジン、公開範囲、価格、SNS 共有設定の確認状態。
- 現在会話での明示承認文。

## 手順

1. 必須確認をすべて埋める。
2. 対象記事、対象操作、公開方式が現在会話で明示されているか確認する。
3. 承認が不足する場合は Stop Message を出して停止する。
4. 承認が足りている場合だけ、ユーザーが指定した操作へ進める。

## 必須確認

- note アカウント、対象記事、title、body、TOP 画像、画像権利。
- tags、magazine、公開範囲、無料/有料、価格。
- SNS 共有設定、外部告知設定。
- 下書き保存、preview、事実確認、秘密情報除外、内部メモ除外。
- 即時公開か予約投稿か。予約なら日時と timezone。
- 公開日やテーマの助言を公式扱いする場合は、創作カレンダーなどの source URL を確認する。固定の「おすすめ公開時刻」は公式未確認として扱う。
- 予約投稿日時が note 公式メンテナンス告知の停止予定期間に重なる場合は、メンテナンス後に順次投稿される可能性を確認し、ユーザーへ明示する。
- 現在の会話で対象記事と操作を特定した明示承認があるか。

## 停止条件

- 対象記事、対象操作、公開方式のどれかが Unknown。
- QA、画像権利、秘密情報除外、内部メモ除外が未確認。
- 現在会話で対象記事と操作を特定した明示承認がない。

## 判定

承認あり:
- 対象記事、対象操作、公開方式が現在会話で明示されている。
- QA、画像権利、秘密情報除外、内部メモ除外が確認済み。
- その場合だけ、ユーザーが指定した操作へ進める。

承認なし:
- Stop Message を出して停止する。
- 「公開して」「投稿して」だけでは不十分。対象記事と操作を特定してもらう。

## Stop Message

```text
ここで停止します。
- Note 画面: 公開/投稿/予約確定ボタンを押す手前
- 確認済み: タイトル / 本文 / TOP画像 / タグ / マガジン / 公開範囲 / 無料・有料 / 価格 / SNS共有設定 / 下書き保存 / プレビュー / 事実確認 / 秘密情報除外
- 未実行: 公開 / 予約投稿 / SNS共有 / 外部告知

対象記事と操作を明示して、最終承認をもらうまで押しません。
```

## Closeout Evidence

- 確認済み項目。
- 未確認項目。
- 実行していない public action。
- 最終承認の有無。
